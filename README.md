# OM Core Documentation

**[Try Open Modeling in your browser](https://om.cloudcell.nz/)** — the free browser-based modeling application, with local WebAssembly calculations and no registration required.

This repository contains documentation, modeling guides, examples, and reference material for OM Core.

OM Core is a multidimensional modeling engine for building structured financial, operational, and analytical models.

The source code repository is:

[cloudcell/om-core](https://github.com/cloudcell/om-core)
